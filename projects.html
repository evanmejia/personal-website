Shellbound Launcher

  • Go
  • Wails v2
  • Proxmox LXC
  • Nginx CDN

Shellbound is a cross-platform game launcher and distribution pipeline built to solve the core onboarding problem of a private MMO community: securely delivering, patching, and updating a 9 GB game client on a zero-dollar infrastructure budget. Built as a Wails v2 desktop app (Go backend, vanilla JavaScript frontend) backed by a self-hosted CDN running in a Proxmox LXC container on an isolated DMZ VLAN, it replaces risky, full-client re-downloads with resumable, SHA-256-verified delta updates. To protect players from supply-chain tampering, every release is cryptographically signed with minisign/Ed25519, verified against a signed manifest, and delivered over pinned TLS with a fail-closed security model—while also integrating account registration, a one-click addon manager, and a Ghost-powered news feed directly into the client.

Phaworma

  • Go
  • PocketBase
  • Proxmox LXC
  • Nginx Proxy Manager

Phaworma (live at forms.evanmejia.com) is a self-hosted, ephemeral form builder. Privacy-first, packaged as a single Go binary (built on PocketBase and SQLite). Each form lives in its own isolated database table with a 1-to-30-day lifespan; an hourly purge drops expired tables from disk and retires the short link with a 410 Gone. Features single-use claim-token invites, Argon2id form passwords, strict CSP, and cascading account deletion—paired with a zero-CDN vanilla JS SPA. Deployed on Proxmox LXC in production and available as a Docker image for self-hosters.

On-Prem AI Analytics Pipeline

  • Open WebUI
  • Vanna
  • Unstract
  • MindsDB

While modern AI makes it easy to query databases and extract data from messy documents, uploading sensitive county records (like case notes and SSNs) to an external cloud is a strict compliance violation. To solve this, I built an On-Prem AI Analytics Pipeline: a live production deployment running entirely on local dual-GPU hardware and a dedicated analyst workstation with zero external data transmission. Instead of relying on a single vendor platform, I composed four open-source tools where each layer owns one job: Open WebUI serves as the unified control room for local models and workflows, Vanna translates plain-language questions into complex SQL queries, Unstract extracts clean JSON records from messy PDFs and forms, and MindsDB federates live databases to automate data updates in place. Analysts use the pipeline to query dense datasets, clean up legacy records, and transform mountains of unstructured case notes into structured database tables—turning what used to be slow, manual passes into a single conversation. It delivers 100% data locality, zero per-seat cost, and no vendor lock-in. Data remains completely air-gapped from external networks.
