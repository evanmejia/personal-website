Project

Shellbound Launcher

A self-hosted game launcher that delivers a 9 GB client, patches, and updates from its own CDN.

  • Go
  • Wails v2
  • Proxmox LXC
  • Nginx CDN

Problem

Private game servers need a reliable front door: delivering a 9 GB game client, continuous patches, and launcher updates to players — without bloated installers, full re-downloads, or broken patch states.

Solution & Metrics

A Wails v2 desktop app (Go backend, vanilla-JS frontend) backed by a self-hosted CDN on a Proxmox LXC. Resumable downloads with SHA-256 verification, manifest diffing so players fetch only changed files, atomic self-update, and a one-command release pipeline — patch traffic drops from full-client re-downloads to delta-only.

Project

Phaworma

An ephemeral form builder where every form — and its data — self-destructs on schedule.

  • Go
  • PocketBase
  • Proxmox LXC
  • Nginx Proxy Manager

Problem

SaaS form tools keep every response forever — vendor lock-in, privacy risk, and stale data nobody cleans up.

Solution & Metrics

A self-hosted, privacy-first form builder running as a single Go binary (PocketBase extended as an application framework) on one Proxmox LXC — live at forms.evanmejia.com. Every form gets an isolated data collection with a lifespan (1 day–1 month); an hourly purge cron physically drops expired tables from disk and its link answers 410 Gone. Zero stale data by design, zero SaaS cost.

Project

On-Prem AI Data Analysis Stack

Agentic data analysis, fully self-hosted — the data never leaves the rack.

  • OpenClaw
  • WrenAI
  • Unstract
  • OpenRefine

Problem

Teams want AI-driven data analysis — natural-language queries, document extraction, data cleansing — but SaaS AI means shipping sensitive data to a vendor’s cloud.

Solution & Metrics

A fully on-prem agentic stack on Proxmox: OpenClaw as the local AI agent (chat-driven, persistent memory, skill-based orchestration), WrenAI for natural-language-to-SQL, Unstract for document intelligence, and OpenRefine for data cleansing. 100% data locality, zero per-seat SaaS cost, no vendor lock-in.
