Shellbound Launcher

  • Go
  • Wails v2
  • Proxmox LXC
  • Nginx CDN
screenshot / demo

Cross-platform desktop launcher for a 9GB MMO game client, built with zero infrastructure budget.

Replaced player-to-player patch sharing via a GitHub repo with a self-hosted, delta-patched CDN—signed, verified updates delivered through a single front-end that makes downloading and installing a few clicks.

Read more

I transformed the Shellbound MMO player experience by building a custom, cross-platform launcher to manage its 9GB game client. Facing zero infrastructure budget, I engineered a solution using a Wails v2 Go/JS backend and a self-hosted Proxmox-based CDN to provide seamless, delta-only updates that drastically reduced patch traffic. I prioritized security by implementing Ed25519 digital signatures and TLS pinning, ensuring that every update is verified as authentic and protected against malicious tampering. This all-in-one tool streamlined the entire player lifecycle—from account creation and news updates to automated addon management—replacing cumbersome manual processes with a single, trusted, and highly efficient desktop application for Windows and Linux.

Phaworma

  • Go
  • PocketBase
  • Proxmox LXC
  • Nginx Proxy Manager
screenshot / demo

An ephemeral form builder—forms that collect exactly what you need, then destroy themselves.

Self-hosted and free, with single-use invite tokens and a total-erasure policy: nothing survives the form's lifecycle.

Read more

I built Phaworma (a play on shawarma) to serve up a better way to collect data without the 'forever' baggage of traditional tools. Instead of hoarding data indefinitely, Phaworma provides compact ephemeral forms designed to disappear. Using an efficient Go architecture, I engineered a system that wraps each form in a strict Lifecycle, automatically purging expired data from the disk so nothing stale is ever left on the menu. I also wrapped every invite in a single use token to ensure privacy and built a total erasure policy so that when a user is done, their data is gone for good. It is a lightweight and secure solution that lets you collect exactly what you need and nothing more.

On-Prem Gov AI Pipeline

  • Open WebUI
  • Vanna
  • Unstract
  • MindsDB
screenshot / demo

A fully air-gapped AI analytics stack for sensitive county records—natural language to structured data, 100% local.

High-performance text-to-SQL and document extraction with zero external transmission and zero cloud cost.

Read more

To enable AI-driven insights without violating strict compliance regulations regarding sensitive county records, I engineered a fully air-gapped, on-premise AI analytics pipeline. Deployed on local dual-GPU hardware, the system integrates a specialized stack of open-source tools: Open WebUI for a unified control interface, Vanna for text-to-SQL translation, Unstract for unstructured data extraction, and MindsDB for database federation. This architecture allows analysts to transform massive volumes of unstructured case notes and legacy documents into structured database tables via natural language. The resulting pipeline ensures 100% data locality and zero external transmission, providing a high-performance, zero-cost alternative to cloud-based AI providers.
